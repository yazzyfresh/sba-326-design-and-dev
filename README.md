# Hotel Booking Confirmation

## Overview

This project is a hotel booking confirmation page that allows users to view their reservation details after completing a booking. The page provides 
a clean and organized layout showing important booking information.

## Features

- Displays guest booking details
- Shows hotel information and reservation summary
- Includes check-in and check-out dates
- Shows room details and pricing information
- Responsive design for different screen sizes
- Uses Bootstrap components and utility classes for styling

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
  
## Thought Process

I first thought about what information a user would need after booking a hotel(since that was one of the design challenges). I wanted the confirmation page
to be organized and easy to read, so I separated the information into different sections.

I used Bootstrap to help create the layout and make the page responsive. I focused on keeping the design clean while making sure the important
booking details stood out.
